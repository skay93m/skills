# Syntopical Map

This skill runs Adler Level 4, Syntopical Reading. The coach maps a controversy across three to five conflicting sources and outlines updates to the student's permanent Concept Notes. Work through the steps in order.

## Steps

### Read the Governing Documents

Read SOUL.md, ACADEMIC_STANDARDS.md, GLOSSARY.md and RESOURCES.md from the working directory, by bare file name. Apply the Socratic Academic Fellow mode and the Ghostwriting Boundary in SOUL.md. The Socratic Academic Fellow rules in SOUL.md apply. Apply the citation standard in section 6.4 of ACADEMIC_STANDARDS.md. Take the vault's concepts/ folder from RESOURCES.md. If one of these files is missing, name it to the student and stop before selecting any source.

### Select the Sources

Ask for three to five sources that take conflicting positions on one question. If the student offers fewer than three, ask them to widen the set. If the student offers more than five, ask them to narrow it. Each source should already have a record from `/source-discover`.

### Map the Controversy

State the question the sources disagree about, in the student's own words. For each source, ask what it answers that question with, and where it stops. The Socratic Academic Fellow rules in SOUL.md apply.

### Place the Sources on the Idea Compass

Ask the student to place each source in one or more of the four quadrants below, and to give a reason for each placement. Take the quadrants in this order.

#### North: Upstream Origins

The philosophical or doctrinal roots that each source draws on.

#### South: Downstream Consequences

The clinical, legislative, or societal consequences that follow from each position.

#### East: Allied Theories and Jurisdictions

Complementary theories and other jurisdictions that support or illuminate a position.

#### West: Counter-Arguments and Tensions

Direct counter-arguments, opposing precedents, and tensions that cannot be reconciled.

### Outline the Concept Note Updates

Outline updates to the permanent Concept Note for each concept the map touches, recording what was done and what comes next. Check the `concepts/` folder for an existing note first, and update it rather than create a duplicate. The coach never deletes or overwrites a Concept Note. Offer only the headings and prompting questions beneath them:

- Definition: the student's own definition, with its source.
- Upstream Roots: the material from North.
- Downstream Consequences: the material from South.
- Allied Positions: the material from East.
- Tensions: the material from West, including what remains unreconciled.
- Sources: the recorded entries that the note relies on.
