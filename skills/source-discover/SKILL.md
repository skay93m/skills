# Source Discover

This skill records a source at Adler Level 1, Elementary Reading. The aim is to identify the source and record it, not to understand its argument. Work through the steps in order.

## Steps

### Read the Governing Documents

Read SOUL.md, ACADEMIC_STANDARDS.md and RESOURCES.md from the working directory, by bare file name. Apply the Socratic Academic Fellow mode and the flag-only linter rule in SOUL.md, the citation standard in ACADEMIC_STANDARDS.md, and the Zotero PDFs entry in RESOURCES.md. If one of these files is missing, name it to the student and stop before recording any source.

### Receive the Source

Ask for the source as the student holds it: the full citation from the reading list or the title page. Ask one question at a time. Do not look up or fill in details from memory, as section 6.4 of ACADEMIC_STANDARDS.md requires.

### Record the Zotero Fields

Arrange the details the student supplies into these Zotero fields: Item Type, Title, Author, Date, Publication (journal, court, or publisher), Volume, Issue, Pages, Report Series, Neutral Citation, URL, DOI, and Extra. Mark every field the student has not supplied as `missing`. Leave the Abstract field blank for the student, because the coach never writes abstracts.

### Verify the OSCOLA Syntax

Check the citation against section 4 of ACADEMIC_STANDARDS.md, rule by rule, covering the case name, neutral citation, court identifier, pinpoint, statute and journal article rules, and the punctuation rule in section 3 of ACADEMIC_STANDARDS.md. Report each check as a pass or a flag under the flag-only linter rule in SOUL.md, for example 'Line 1, article title: ...'.

A syntax check is not an authority check. Authority verification is governed by section 6.4 of ACADEMIC_STANDARDS.md. Wait for the student to correct each flagged line before moving on.

### Note the PDF Location

Record the PDF as a linked attachment in Zotero, not as an upload, in the Zotero PDFs folder named in RESOURCES.md. If the student has no PDF yet, mark the attachment as `not yet stored`. Record what was done and what comes next in the discovery note.
