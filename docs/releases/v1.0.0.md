## Executive Summary

`v1.0.0` is the Sprint 1 baseline for the Agile governance layer of `skay93m/skills`. It adds a mandatory ambient writing standard as a skill (`style`), retires the superseded daily knowledge maintenance code, and single-sources the repository's style rules and sprint vocabulary. The sprint was executed under Work Order 1 (`docs/work-orders/wo-1.md`).

### 1. Style Skill (#160)

- New `skills/style/` skill with the mandatory rules: British English, zero em dashes, zero horizontal dividers, clean markdown tables, no emoji, and line budgets.
- Reference files: `language-rules.md`, `markdown-layout.md`, and `global-agent-setup.md`.
- New manifest `manifests/style.yaml`.
- `AGENTS.md` refactored around the native GitHub Agile framework (Milestones as sprints, epics, and tickets) and the Chief of Staff protocol.

### 2. Retired Maintenance Code (#114)

- Removed the superseded report-only maintenance script `scripts/knowledge_maintenance.py` (467 lines).
- Removed its test module `tests/test_knowledge_maintenance.py` (652 lines) and fixture `tests/fixtures/dry_run_snapshot.json` (108 lines).
- Updated `docs/specs/daily-knowledge-maintenance.md` and `tests/test_npx_packaging.py` to match.

### 3. Glossary and Single-Sourced Style Rules (#160)

- `GLOSSARY.md` gains the terms **Sprint** (a GitHub Milestone), **Epic** (a top-level issue grouping sub-issues), and **Ticket** (an atomic issue labelled `ready-for-agent`).
- Style rules now live only in `skills/style/SKILL.md`. The duplicate observation in `GLOSSARY.md` points there.
- `docs/agents/coordinator-protocol.md` now points to the single style source.

### 4. Execution Ledger (WO-1)

- `docs/work-orders/wo-1.md` records the release halt and the ticket execution ledger.
