# Proposed glossary terms

Proposed only. These are not in `GLOSSARY.md`; adding them is a later decision through the domain-modeling step. Source: #87 and #90.

**public seam**:
The vendor-neutral, default-deny contract owned by SS that SW implements. It carries closed vocabulary values, opaque references, counts and capability tokens, and nothing else.

**compatibility binding**:
SW's private mapping from a seam capability to its backend. It stays private to SW; the public repository holds no binding.

**opaque reference**:
A token generated by SW per run or per grant set that is not derived from private content and reveals nothing. Run references and grant references are opaque references.

**mutation grant**:
A human-approved allowlist entry for one capability and one operation class. A mode, a role or a passing test is not a mutation grant.

**seam ratification**:
Syafiq's recorded approval of a seam version, bound to a commit SHA in a GitHub issue or pull request. Agreement between SS and SW is never ratification, and ratification does not activate a binding.
